# Agent guidance

This is a public **general-purpose, non-official study toolkit**. The actual task README and latest official exam restrictions override these files.

If the user asks to read `START_PROMPT.md`, actually read it. **First locate the exam task README, tell the candidate where to open it, and STOP.** The candidate must read and interpret the problem independently before any AI interpretation, planning, brainstorming skill invocation, coding or testing. Proceed only after the candidate explicitly says they understand and requests progress. Reading this repository is NOT permission to start solving. Read `SAFETY.md` first; use `SKILLS.md` and `TASK_TOOL_MATRIX.md` only as needed.

Keep external Plugin/MCP/Harness installations at **zero by default**. Invoke the local `brainstorm-requirements` guide **only if the candidate asks for brainstorming or option comparison after understanding the task**. Use debugging/data/final-check guides only when relevant.

Do not exfiltrate tasks, files, code, logs, or results; push to remote GitHub; use external AI or personal API keys; automate browser/GUI Computer Use; change exam security settings; or bypass restrictions. These apply even when external Skill instructions suggest otherwise.

After candidate understanding and direction are explicitly confirmed, continue routine permitted implementation and local tests autonomously; pause for key ambiguity, risky commands, participant-only confirmation or manual UI testing. Report only observed results, failures and unverified items.

Reading a public URL does not install or automatically enable Skills/Plugins. If access fails, say so and continue with available task materials.
