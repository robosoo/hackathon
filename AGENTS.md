# Agent guidance — candidate leads task understanding

This repository is a public, general-purpose study toolkit, not the official task or an answer key. **The actual exam task README and the latest official rules override all repository instructions.**

When the candidate asks you to read this repository's `START_PROMPT.md`:

1. **Actually read `START_PROMPT.md`** and the short `SAFETY.md`. Do not repeat the repository URL or ask the candidate to paste your own starting instructions again.
2. **Actually open and read the real exam task README and provided materials inside the exam workspace.** Do not merely point to a file location or confuse the study repository README with the exam task README.
3. Until the candidate has independently read and interpreted the task and explicitly gives you direction, **do not summarize or interpret the task, invoke brainstorming Skills, plan a solution, code, or test**. Acknowledge only whether reading succeeded, then wait.
4. After the candidate gives their understanding and requests assistance, compare it to the task requirements, flag only consequential omissions, and help with the specifically requested work. Use local `brainstorm-requirements` **only when brainstorming is requested**.
5. Once a solution direction is agreed, implement and test routine permitted changes without repeatedly asking for permission; keep substantial business decisions and candidate-only manual UI checks with the candidate.

Default external Plugin/MCP/Harness installations to **zero**. Prefer the built-in Codex workspace and the existing focused debugging, data-quality, and final-verification Skills. Do not claim a Skill/Plugin was installed merely because it is linked.

Never export task files/code/logs/results or personal information to external systems, Git Push, connect other AI or personal API keys, import private resources, upgrade Codex, automate Browser/GUI Computer Use, bypass restrictions, or replace the solution wholesale with outside code. Follow `SAFETY.md` and all newer official limits. Report **observed PASS / FAIL / unverified** outcomes accurately.

If a source cannot be read, state that plainly. These are natural-language instructions, not guaranteed technical enforcement.
