# 데이터 품질 점검

이 문서는 공개 도구함이 직접 작성한 학습용 지침이며, 외부 DB 또는 클라우드 연결이 필요하지 않습니다.

## 순서
1. 입력 파일과 컬럼 설명을 읽고 행 단위(거래·Lot·이벤트 등)를 정합니다.
2. 식별자/키의 유일성, 중복 기록, 빈 값, 데이터 타입, 잘못된 날짜와 단위를 점검합니다.
3. 수치 집계라면 분자·분모를 명시하고 0/결측 분모를 어떻게 처리할지 정합니다.
4. 5% **초과**와 5% **이상**처럼 경계 연산자가 다른 경우를 별도로 검사합니다.
5. 명세에 없는 보정·삭제·추정 값은 마음대로 적용하지 않고 불확실성을 기록합니다.
6. 단순 합계·평균 또는 표본 일부를 독립 계산해 AI 출력과 대조합니다.
7. 관찰된 상관관계와 인과관계 주장에 필요한 근거를 구분합니다.
