# 오류 원인 분석 및 수정 — 오류 원인을 확인하고 고치기

이 문서는 학습용으로 직접 작성된 Skill입니다.

## 순서
1. 실패한 단계와 원래 기대한 결과를 짧게 기술합니다.
2. 로그·오류 메시지·관련 파일을 실제로 읽습니다.
3. 같은 조건에서 실패를 재현할 수 있는지 확인합니다.
4. 수정 전 코드의 입력·출력·최근 변경 사항을 비교해 가능한 원인을 좁힙니다.
5. **확인한 원인에 관련된 부분만** 최소한으로 수정합니다.
6. 동일한 실패 테스트를 다시 실행하고 다른 정상 기능이 깨지지 않았는지 확인합니다.
7. 원인을 찾지 못했다면 추측 수정이나 성공 주장을 하지 않고 미확인으로 보고합니다.
